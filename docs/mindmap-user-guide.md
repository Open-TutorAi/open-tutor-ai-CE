# Mind Map — User Guide

## What is it?
The mind map feature lets you visually organize the concepts you've studied during a chat session with the AI tutor.

## How to use it

1. **Start a chat** with the tutor on any topic
2. Click **"Carte Mentale"** below the chat
3. You'll see **suggested concepts** extracted from your session — click to add them as nodes
4. **Customize your map:**
   - Drag nodes to reposition
   - Double-click to edit a node's text
   - Use the link tool 🔗 + click 2 nodes to connect them
   - Select a node + pick a color
5. Click **"Vérifier ma carte"** to have the AI agent check your map
6. Two outcomes:
   - ✅ **Validated**: you get feedback + can download your map as PDF
   - ⚠️ **Needs improvement**: you can add more concepts yourself or let the agent complete it
7. Click **"Télécharger PDF"** to save your validated mind map
