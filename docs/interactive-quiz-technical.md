# Interactive Quiz & Pedagogical Shortcuts — Technical Documentation

## Overview

This document describes the technical implementation of two features added to the Open TutorAI student chat interface:

1. **Interactive Quiz** (`InteractiveQuiz.svelte`) — A modal MCQ quiz generated by the LLM with click-to-answer interaction and immediate feedback.
2. **"Je n'ai pas compris" button** (`PedagogicalShortcuts.svelte`) — A pedagogical shortcut that re-explains the current concept in 3 different ways.

## Components

### 1. InteractiveQuiz.svelte

#### Purpose
Generates and displays an interactive MCQ quiz in a modal overlay. The quiz is generated by the local LLM (Ollama) based on the current conversation context.

#### Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `conversationContext` | `string` | `''` | The current conversation topic used to generate relevant questions |

#### Exported Methods
| Method | Parameters | Description |
|--------|------------|-------------|
| `generate(context)` | `context: string` | Triggers quiz generation from the LLM |

#### Quiz Phases
```
idle → loading → quiz → results
                ↑         |
                └── retry ┘
         (on error) → error
```

| Phase | Description |
|-------|-------------|
| `idle` | Modal hidden |
| `loading` | Spinner shown, LLM generating questions |
| `quiz` | Questions displayed one by one |
| `results` | Final score and recap shown |
| `error` | Error message with retry button |

#### LLM Integration

The component uses `generateChatCompletion` from `$lib/apis/ollama` with **streaming enabled**:

```typescript
const [res, controller] = await generateChatCompletion(token, {
  model: selectedModel,
  messages: [
    { role: 'system', content: 'Tu es un générateur de quiz. Réponds UNIQUEMENT en JSON valide.' },
    { role: 'user', content: prompt }
  ],
  stream: true  // Required: non-streaming causes 502 timeout
});
```

> ⚠️ **Important**: `stream: false` causes a 502 error because the proxy timeout (120s) is still exceeded for large responses. Always use `stream: true`.

#### Stream Reading

The component reads the Ollama stream line by line and accumulates the JSON response:

```typescript
while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  const chunk = decoder.decode(value, { stream: true });
  for (const line of chunk.split('\n')) {
    if (!line.trim()) continue;
    try {
      const parsed = JSON.parse(line);
      if (parsed?.message?.content) fullText += parsed.message.content;
      if (parsed?.done) break;
    } catch {}
  }
}
```

#### Expected JSON Format

The LLM must return a JSON object in this exact format:

```json
{
  "questions": [
    {
      "question": "What is an algorithm?",
      "options": ["A: Option 1", "B: Option 2", "C: Option 3", "D: Option 4"],
      "correct": "B",
      "explanation": "Short explanation of why B is correct.",
      "recap": "Brief concept re-explanation if the student answers incorrectly."
    }
  ]
}
```

#### Events Dispatched
| Event | Payload | Description |
|-------|---------|-------------|
| `close` | none | User closed the quiz modal |
| `error` | `string` | LLM generation failed |

### 2. PedagogicalShortcuts.svelte

#### Purpose
Displays a toolbar of pedagogical shortcuts in the chat input area. Modified to:
- Add a **"Je n'ai pas compris"** button that re-explains the concept 3 ways
- Make the **"Multiple Choice"** button open the interactive quiz modal instead of sending a plain text prompt

#### Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `conversationContext` | `string` | `''` | Passed to `InteractiveQuiz` for context-aware quiz generation |

#### Events Dispatched
| Event | Payload | Description |
|-------|---------|-------------|
| `submit` | `string` | Text prompt to send to the chat |

#### Shortcut Actions

| Button | Type | Action |
|--------|------|--------|
| Difficulty | Menu | Sends difficulty adjustment prompt |
| Understand | Menu | Sends re-explanation prompt (analogy/example/visual) |
| Je n'ai pas compris | Direct | Sends 3-way re-explanation prompt |
| Summarize | Direct | Sends summarization prompt |
| Next Step | Direct | Sends next concept prompt |
| Quiz → Open Ended | Direct | Sends open question prompt |
| Quiz → Multiple Choice | **Interactive** | Opens InteractiveQuiz modal |
| Quiz → Concept Link | Direct | Sends concept link prompt |

#### "Je n'ai pas compris" Prompt

```
Je n'ai pas compris ce que tu viens d'expliquer. Réexplique ce concept de 3 façons différentes :
🔁 Une analogie simple tirée de la vie quotidienne
💡 Un exemple concret et pratique, étape par étape
📊 Un schéma ou tableau textuel qui organise les idées
Utilise un langage simple, clair, et adapté à un étudiant débutant.
```

## Backend Fix: Proxy Timeout

### Problem
The default proxy timeout in `ai/providers/proxy.py` was **30 seconds**, which was insufficient for LLM quiz generation (typically 30–90 seconds for `qwen2.5:1.5b`).

### Root Cause
```python
# Before (caused 502 errors)
TIMEOUT_DEFAULT = 30.0
```

The `proxy_json` function uses `TIMEOUT_DEFAULT` for non-streaming requests. When the LLM takes more than 30s to generate the quiz JSON, `httpx` throws a `ReadTimeout` exception, caught as a generic `Exception` → 502 Bad Gateway.

### Fix
```python
# After
TIMEOUT_DEFAULT = 120.0
```

```
ai/providers/proxy.py — line 11
```

## Known Limitations

| Limitation | Impact | Workaround |
|------------|--------|------------|
| Quiz generation takes 30–90s | User must wait | Spinner shown during generation |
| `conversationContext` not automatically populated | Quiz may not be topic-specific | Pass chat history from parent component |
| Small models (1.5b) may produce invalid JSON | Quiz fails to parse | Retry button available; use larger model for better results |
| Only 2 questions generated | Limited quiz depth | Increase `num_predict` and adjust prompt |

## Testing

### Manual Test Steps

1. Start a conversation with the student tutor
2. Ask a question (e.g., "Explain variables in algorithms")
3. Wait for the LLM response
4. Click **Quiz** → **Multiple Choice**
5. Verify:
   - [ ] Loading spinner appears
   - [ ] 2 questions are generated (10–60s)
   - [ ] Clicking correct answer shows green ✅ + explanation
   - [ ] Clicking wrong answer shows red ❌ + correct answer highlighted + recap
   - [ ] "Next question" button advances to next question
   - [ ] Final results screen shows score and recap
   - [ ] "Retry" button resets the quiz

6. Click **Je n'ai pas compris**
7. Verify:
   - [ ] LLM responds with 3-part re-explanation
   - [ ] Response includes analogy, example, and table/diagram

## Configuration

No additional configuration required. The feature uses the model already selected in the student chat interface.

To change the default model for quiz generation, modify `InteractiveQuiz.svelte`:

```typescript
const selectedModel = currentSettings?.models?.[0] 
  || currentModels?.[0]?.id 
  || 'qwen2.5:1.5b';  // ← Change default here
```
