👤 USER STORY 1 — Interaction Vocale avec l'IA

🎯 Objectif de cette User Story

L'étudiant peut parler à l'IA avec son microphone et écouter les réponses lues à voix haute. Aucune frappe au clavier n'est nécessaire.

📁 Fichiers implémentés

  • VoiceRecording.svelte — Capture audio, visualiseur d'onde, transcription temps réel
  • MessageInput.svelte — Bouton micro, gestion du mode enregistrement
  • ResponseMessage.svelte — Bouton 🔊 pour lire la réponse IA à voix haute

🔑 Technologies clés

  • Web Speech API (SpeechRecognition) — transcription vocale dans le navigateur
  • SpeechSynthesis API — lecture vocale des réponses
  • AudioContext + AnalyserNode — visualiseur d'onde animé pendant l'écoute

1.2 Diagramme d'Activité

🔄 Ce que montre ce diagramme

Le flux complet d'une interaction vocale — de quand l'étudiant clique sur le micro jusqu'à la lecture de la réponse IA.

1 Clic sur 🎤 → demande permission microphone
2 Permission accordée → démarrage flux audio + visualiseur
3 Écoute active → transcription intermédiaire en gris italique
4 ✓ Confirmer → texte envoyé au chat → réponse IA générée
5 Optionnel : 🔊 Clic → réponse lue à voix haute en FR ou EN

⚠️ Si la permission est refusée ou le réseau bloque, un message d'erreur explicatif s'affiche.

🎯 Objectif de cette User Story

L'étudiant peut générer une vidéo YouTube explicative directement dans le chat, sans quitter son espace de travail. La vidéo s'affiche dans un lecteur intégré avec tous les contrôles.

📁 Fichiers implémentés

  • PedagogicalShortcuts.svelte — Panneau de recherche vidéo, lecture YouTube Lite Embed
  • gateway/http/routers/youtube.py — API backend FastAPI qui scrape YouTube
  • ResponseMessage.svelte — Affiche vidéo intégrée si l'IA inclut un tag [YOUTUBE: ID]

🔑 Deux déclencheurs

  • Bouton 🎥 dans les raccourcis → panneau de recherche manuelle
  • Tag [YOUTUBE: ID] dans la réponse IA → vidéo automatiquement intégrée dans la bulle

2.2 Diagramme d'Activité — Raccourcis Pédagogiques

🔄 Flux : Recherche via bouton 🎥

Comment fonctionne la recherche vidéo déclenchée par l'étudiant via le panneau de raccourcis.

1 Clic 🎥 → panneau de recherche apparaît (champ texte bloqué dans chat)
2 Saisie du sujet (texte ou 🎤 micro) → clic Rechercher
3 Appel GET /youtube/search?q=sujet → backend scrape YouTube
4 Jusqu'à 5 IDs vidéo retournés → miniatures affichées avec navigation ‹ ›
5 Clic ▶ → iframe chargée (Lite Embed — chargement lazy pour éviter blocages CORS)
6 Vidéo joue avec contrôles natifs YouTube (Pause, Seek, Plein écran)

2.3 Diagramme d'Activité — Réponse IA

🔄 Flux : Vidéo via réponse IA

Comment une vidéo peut apparaître automatiquement si l'IA décide d'en suggérer une.

1 L'IA inclut [YOUTUBE: VIDEO_ID] dans sa réponse
2 ResponseMessage.svelte parse la réponse avec une regex
3 Le tag est supprimé du texte affiché → remplacé par une carte vidéo
4 Miniature YouTube affichée dans la bulle de discussion
5 Clic → modal plein écran s'ouvre avec l'iframe youtube-nocookie.com
6 Clic hors modal ou ✕ → modal fermé, vidéo arrêtée

2.4 Diagramme de Séquence — Raccourcis

🔁 Séquence détaillée : Raccourcis → YouTube

Chaque appel réseau et changement d'état dans l'ordre exact d'exécution.

1 PedagogicalShortcuts → fetch /youtube/search → YouTubeRouter FastAPI
2 YouTubeRouter → GET youtube.com/results?search_query=...&sp=EgIQAQ (filtre vidéos)
3 Extraction regex des IDs → déduplication → max 5 IDs retournés au frontend
4 Frontend affiche miniatures (img.youtube.com/vi/ID/hqdefault.jpg)
5 Clic ▶ → videoActivated = true → iframe chargée (chargement différé)

💡 Le paramètre sp=EgIQAQ filtre uniquement les vidéos (pas les playlists ni chaînes)

2.5 Diagramme de Séquence — Réponse IA

🔁 Séquence détaillée : Réponse IA → Vidéo intégrée

Comment la vidéo passe de la réponse IA au lecteur dans la bulle de chat.

1 Serveur IA stream réponse avec [YOUTUBE: abc123]
